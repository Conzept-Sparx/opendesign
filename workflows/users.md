title: Users, goals and proto-personas
description: Identify users and their goals and write evidence-tagged proto-personas in opendesign/users.md. Use when the designer asks for personas, user groups, user goals or "who are we designing for".
---
**Goal:** a small set of personas whose every attribute shows how much we actually know.

1. Read brief.md and all research/evidence files.
2. List the user groups the product touches (primary, secondary, affected-but-not-using). Ask the designer to confirm which ones this project designs for.
3. For each confirmed group, write a persona section `## P<n> — <name>` in users.md with **Who**, **Goals** (G<n>, numbered across the whole file), **Frustrations / risks** (F<n>), **Context**.
4. Tag every bullet: `[observed: EV-00x]`, `[research: EV-00x]` or `[assumed]`. Only cite EV files that exist.
5. Prefer 1–3 personas. More usually means the brief is too broad; say so.
6. Report the evidence share per persona (for example "P1: 5 observed, 0 research, 7 assumed") and, if over half is assumed, recommend which research would help most.
7. Recommend `journeys` next.

No stock-photo biographies, names of hobbies or invented quotes. Every line should be able to change a design decision.
