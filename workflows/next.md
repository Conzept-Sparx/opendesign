id: next
title: Next step
description: Check where the OpenDesign project stands and recommend or start the next workflow. Use when the designer says "what's next", "where are we", "continue", or starts a session.
---
1. Run `opendesign status` in the terminal and read its output.
2. Read `opendesign/CONVENTIONS.md` if you haven't this session.
3. Summarise for the designer in a few lines: what exists, what's thin (for example, personas mostly `[assumed]`, requirements not covered by any screen, open questions), and what verify last reported.
4. Recommend ONE next workflow and why, using this order as the default path:
   system → brief → research → users → journeys → requirements → ideate → structure → screen → generate → critique → verify → rationale.
   Skip ahead only when the earlier artifact is good enough for the next step; say so when you do.
5. Ask whether to start it. If the designer agrees, follow that workflow's instructions.
