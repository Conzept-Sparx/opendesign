# Design system

Generators use ONLY the tokens, components and variants listed here.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--primary` | `#0F172A` | Primary action |
| `--background` | `#FFFFFF` | App background |
| `--radius` | `8px` | Corners |

## Variants

| Component | Variant | Use |
|---|---|---|
| Button | `default` | One primary action per view |
| Button | `outline` | Secondary actions |
| Button | `ghost` | Tertiary actions, icon buttons |
| Button | `link` | Inline text actions |
| Badge | `default` | Neutral label |
| Alert | `destructive` | Errors |

## Components (shadcn/ui)

| Component | Import |
|---|---|
| Button | `@/components/ui/button` |
| Card | `@/components/ui/card` |
| Input | `@/components/ui/input` |
| Badge | `@/components/ui/badge` |
| Alert | `@/components/ui/alert` |
